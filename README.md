# Market Labs Provenance Standard

This repository defines the shared provenance, evidence, naming, disclosure, and relationship standards used across independent Market Labs research projects.

Individual projects maintain their own repositories, canonical entities, communities, and research records.

Adopting this standard does not imply that participating projects are affiliated with one another, share the same audience, or belong to one universal public knowledge graph.

## Core Principle

One standard. Independent laboratories. Intentional bridges.

## Standard Components

- SCHEMA.md — required artifact fields
- EVIDENCE.md — evidence classifications
- NAMING.md — canonical naming and alias rules
- DISCLOSURES.md — research, market, affiliation, and conflict disclosures
- RELATIONS.md — permitted cross-project relationship types

## Evidence Classes

- Verified
- Corroborated
- Author-Originated
- Proposed
- Future Experiment

## Architecture

Each Market Lab maintains its own:

- GitHub repository
- CANON.md
- research artifacts
- provenance records
- Discord community
- disclosures

Cross-project relationships must be explicitly documented rather than inferred from shared infrastructure.
